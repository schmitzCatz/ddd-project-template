*Guiding questions*

* Which capabilities deliver the desired outcomes?
* Which actors rely on each capability?
* How do capabilities depend on one another?
* Which capabilities are differentiating?

*Expected artifacts*

* Capability map
* Capability descriptions
* Business outcomes
* Capability dependencies
* Prioritization

*Modeling guidelines*

Use verb-noun names where possible. Avoid treating capabilities as services or bounded contexts.
