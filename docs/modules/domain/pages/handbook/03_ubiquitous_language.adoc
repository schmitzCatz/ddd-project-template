== Purpose

Establish shared terms used consistently by domain experts, documentation and code.

====
*Guiding questions*

* Which terms have specific business meanings?
* Where do synonyms or conflicting meanings exist?
* Do meanings differ across contexts?
* Which terms must not be used interchangeably?

*Expected artifacts*

* Glossary table
* Synonyms and forbidden terms
* Context-specific definitions
* Open terminology disputes

*Modeling guidelines*

Define terms with examples and counterexamples. Record the owning context where meanings differ.
